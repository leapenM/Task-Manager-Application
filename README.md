# Task-Manager-Application
Utilizing modern technology to assist the time management of various tasks and turbulent schedule changes. 

### Developmental Notes:
- Utilizing GitHub Flow strategy for development (due to small team size and organizational needs)
   - Branch creation is based on features implemented (new feature => features/[NAME OF FEATURE ADDED])
   - Issues are created based on bugs or steps in developmental process (will update personal project status board when new issues open)
- Sqaush Merging (to maintain a clean git log) with automatic branch deletion
